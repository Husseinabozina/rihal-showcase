# رِحال

منصة لخدمة الحجاج وتشغيل حملات الحج والعمرة، تضم تطبيقين أصليين بـFlutter ولوحة إدارة React وخلفية NestJS وPostgreSQL.

هذا معرض علني للعمل المنفّذ. الكود المصدري خاص، ويمكن ترتيب مراجعة تقنية له. الإصدار الحالي مرحلة تطوير أولى، وليس إطلاقًا إنتاجيًا.

## المنفذ

عرض البرنامج من قاعدة البيانات، إنشاء تحركات من الإدارة، تسجيل حضور كل انتقال مع منع التكرار وتقييد المجموعة، وطلبات مساعدة محفوظة. الواجهة عربية افتراضيًا مع الإنجليزية، ونظام تصميم مشترك وشريط تنقل عائم.

## التحقق

اجتاز التطبيقان الفحص الساكن وبناء iOS للمحاكي. نجح اختباران لواجهة Flutter وثلاثة سيناريوهات تكامل للخلفية. جرى تسجيل حضور حاج من لوحة الإدارة والتحقق من تغير حالته بعد الحفظ.

الخرائط دون اتصال، بقية وحدات التشغيل، التوثيق الإنتاجي وقياس الأداء ما زالت ضمن خطة التنفيذ، ولا تُعرض كمزايا مكتملة.
